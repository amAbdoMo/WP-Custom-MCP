Connect WordPress to Model Context Protocol clients through secure tools, resources, prompts, and transports.

== Installation ==

1. Download `wordpress-mcp.zip` from the GitHub Releases page.
2. In WordPress, go to Plugins > Add New > Upload Plugin and upload the ZIP file.
3. Activate WordPress MCP and configure it under Settings > WordPress MCP.

== Updates ==

Updates are served only from the `wordpress-mcp.zip` asset attached to an official GitHub Release. Source-code archives are not used for updates.
